# cumTempore

A simple clock and timer for keeping time while giving university lectures or talks.

- **Wall clock:** the local time, filling the whole screen.
- **Timer:** a countdown in the style of Google's Clock app. It turns dark red
  during the last five minutes and red once you run over time, then counts upwards.
- The screen stays on while the app is open.

Available for Android, iOS, macOS, Windows and in the web browser (WebAssembly).
